# GearLogs website (gearlogs.com) — repo rules for Claude Code (HYG-3, written 2026-09-04)

The website's owed work lives in the app repo's tracker: `GearLogs/GEARLOGS_PROJECT_TRACKER.md` §5 (5.1 changelog queue · 5.2 FAQ · 5.3 Help Center · 5.4 cards · 5.5 Field Notes · 5.7 published register · 5.8 the drafted copy, written at the app PR's closeout and lifted as-is). Publishing = ticking there in the same pass.

## Shape
A generated, **bilingual** static site (EN + native Hebrew, RTL — since web #70, 2026-09-13; every change ships in BOTH languages, the build refuses a page that lacks its Hebrew). `scripts/build-site.mjs` renders every page from ONE chrome source (`src/chrome.mjs`: header, footer, nav, the language switch) + per-language head metadata (`src/meta/{en,he}.json`) + body fragments (`src/bodies/<slug>.<lang>.html` — `index` (the approved Home Mock: hero, problem, feature rows with real screens, numbers, sector tiles, security, the price strip), `product` (how it works, section by section, then the `cap-card` grid 1.1–1.17, the four steps and the security cards 3.1–3.10 — moved word for word from the old home), `changelog`, `faq` (`faq-item` blocks: `<h2 class="faq-q">` + `<p class="faq-a">`), `guides` (cards 4.1…4.NN), `pricing`, `privacy`, `terms`, `refunds`, `notes` + `notes/<slug>` Field Notes with their JSON-LD `src/bodies/<slug>.jsonld.<lang>.json`), registered in `src/pages.mjs` (structure only: slug, path, chrome, sitemap; `bilingual: true` for every public page; the unlisted `pay` (EN) and `404` (EN + HE) are registered too, with `sitemap: null`). English is written to `dist/`, Hebrew to `dist/he/` (`<html lang="he" dir="rtl">`, reciprocal `hreflang`, self-referencing canonicals), `sitemap.xml` generated; `public/` is copied as-is; the stylesheet is BUNDLED (Stage 2, 2026-09-27): edit ONLY the partials in `src/styles/` (`main.css` imports them in order — tokens first, utilities last; esbuild writes ONE minified `dist/styles/main.css`); every colour, size, radius, shadow and duration is a token in `src/styles/tokens.css`, and `scripts/check-uistd.mjs` refuses a colour literal, an off-scale font size, a second radius (true circles wear `.dot`), a shadow outside the named floating things, a `:focus` rule, tracking or capitals outside the label tokens (Hebrew switches them off) and literal durations — `home-legacy.css` is exempt by name until the home is rebuilt, then deleted; the headers are GENERATED — `dist/_headers` is written by the build from the named policies in `scripts/lib/headers.mjs` (never a hand-copied block per path; the local preview answers with the SAME rules through `headersFor`, so a policy that breaks a page is seen on :4173); no inline code anywhere (no `style=""`, `<style>`, `on…=` or `javascript:` — the build refuses them; the CSP has no `'unsafe-inline'` and no `https:` images except the Paddle page), JSON-LD allowed; `functions/api/geo.js` the language banner). Typed browser scripts live in `src/scripts/` (strict TypeScript, Q8 · A, 2026-09-26): the build bundles each entry in `SCRIPT_BUNDLES` (`scripts/build-site.mjs`) into `dist/js/` with esbuild, `tsc` only type-checks; the contact form (`src/scripts/contact/`) mirrors the server's rules in the GearLogs repo (`supabase/functions/contact-inbound/rules.ts`) and `scripts/check-contact.mjs` runs the same cases. Never edit `dist/`. The chrome is ONE source — never duplicate header or footer in a body. Hebrew reads as a native product, never a calque; a strict EN↔HE semantic proofread before the gate (the 2026-09-13 lesson: automated Hebrew plateaus, a human copywriter is the finish).

## The Stage 2 look (2026-09-27, the approved Home Mock)
- **The chrome** (`src/chrome.mjs`): the header floats transparent over the page's first band (a page that opens without one gets it on ink, `.is-solid`); the bar is Product · Security · Pricing · a click-open **Help** menu (`<details>`, closed on Escape/outside click by `src/scripts/nav/menu.ts`), then the language link · Sign in · Request access (`/contact?reason=access&from=header`); the footer is the ink band with only pages that exist (F1 · A). Words live in `src/i18n.mjs` (`NAV_ITEMS`, `FOOTER_COLUMNS`, EN + HE).
- **The photo band** (F3 · C): every page opens with `<gl-band photo="…">` (the home's is the hero variant) holding `.band-kicker` · ONE `<h1 class="band-title">` · `.band-lede` (· `.band-note`, `.band-trail`; `variant="article"` for a Field Note). `scripts/lib/band.mjs` expands it; the build refuses a page without one. Photos: originals in `assets/photos/` (never deployed, provenance in `PROVENANCE.md`) → `npm run photos` cuts each to a 3:1 strip in three widths into `public/img/photos/` + `manifest.json` (the legal strip is cut above its dated-looking form; the clipboard stays sharp by his pick "Clipboard · A · Crisp, as in the mock").
- **Real app screens** (S2-02): a body writes `<gl-shot id="board">` (optionally `inset="mygear-receipt"`); `scripts/lib/shots.mjs` expands it from `public/img/app/manifest.json` into the ONE frame (the page's language, its alt text, 1600w + the full 2× picture, click to enlarge in the ONE viewer `src/scripts/lightbox/lightbox.ts`). The build refuses an unknown id, a missing language, a picture in the other language and ANY `/img/app/` picture outside a frame. `npm run capture` writes both sizes; a shot may picture one element (`target`) or a rectangle it measures (`clip`). A guide step points at what to press with `marks` (the Director's "Highlights · A · Spotlight + numbers", the outline pulsing, no hotspot): the shot lists the targets in the SCREEN'S reading order, the capture records their boxes per language, `<gl-shot … marks>` draws the dim, the GO outlines and the numbers in SVG, and the step's `<ol class="guide-marks">` lists them in the same order (callout number = list number); the build refuses `marks` on a picture that has none.
- **Section photos**: `<gl-photo name="repair" class="pc-img" sizes="606px">` (`scripts/lib/photo-tags.mjs`, with `<gl-band>`; the home's hero is `<gl-band photo="hero" variant="hero">`). Every photo is decorative (`alt=""`), never captioned as a customer.
- **Motion** (Q11 · A): `src/scripts/motion/motion.ts` — a `.rv` block rises in once, `data-stagger` rows follow one another, `data-to` numbers count up; a guide step's outlines (`marks`) pulse three times when their screen is 60% in view, then rest; hidden only after the script marks `<html class="motion">`; reduced motion = still. The hero's push is CSS, once.
- **Fonts**: IBM Plex self-hosted from @fontsource (`FONT_FILES` in the build copies the files + their OFL licences to `/fonts/`); `src/styles/fonts.css` holds the faces with unicode-range; the head preloads at most two per language.
- **Unlisted pages**: `/pay` (EN, Paddle) and the 404 (EN + HE — Cloudflare Pages serves the NEAREST `404.html`, so `/he/404.html` answers Hebrew misses) are generated from the chrome with `sitemap: null` (no canonical, hreflang or language switch).
- **Contrast over photos is measured, never assumed**: text over a band is judged against the brightest realistic pixel under its own line boxes (all AA on 2026-09-27, lowest 5.55:1).

## Check and ship
`npm run check` also refuses a `#fragment` link whose target page has no such id (check-links), proves the inline-code guard on its cases (check-inline-guard) and walks every page in Chrome with the production CSP PINNED by request interception — every page's own files served over both schemes (the policy's upgrade-insecure-requests asks for https), any failed or 404 own file failing the walk, /api/geo answered as for a visitor in Israel so the Hebrew nudge renders, Paddle loading for real on /pay with its two known refusals named — and an inline-style canary proving the policy is in force (check-csp — the security gate's SEC-PR1-1: the AdGuard app on the Director's PC loosens every CSP on plain-HTTP localhost, so a browser walk of the preview proves nothing about the policy; every CSP proof uses the pinned walk); `npm run perf [-- --base=http://localhost:4173]` prints the speed record (the before/after of any visible change goes into the evidence).
```
npm run check      # tsc · the contact-rules test · the inline guard · the look laws (check-uistd) · build · links · bilingual · the pinned CSP walk
npm run photos     # re-cut the served photo strips from assets/photos/
```
Cloudflare Pages deploys `main`; the GitHub status can stay "pending" after the page is already live — verify with a cache-busted `curl` of the page. Never commit on `main`; `git checkout -b` as its own command; squash-merge when `CLEAN`. A website gate (ui-ux-master on Opus, on a local `vite preview` — port 4173, never the app's 4174) walks every changed page before the PR.

## House style (verified against 57+ entries and 9 notes)
- Changelog: outcomes, never mechanics; `GL-NN` newest first, inserted right after `<div class="changelog">`; NO terminal full stop on a bullet; no dates anywhere on the public site.
- Field Notes voice: the reader is an ops person; useful first, GearLogs only in the last fifth; open on the reader's problem with a concrete scene; short active sentences; British spelling; one pull quote that never repeats the sentence above it; filed by code FN-NNN with a category and a read-time; JSON-LD BlogPosting + BreadcrumbList; the notes page's Blog JSON-LD lists EVERY note.
- Never: "free trial" / "sign up" CTAs (invite-only), emoji, self-praise, "+N more", mobile layouts.
- Every public claim is checked against the app's own strings and limits before it is written; when a control is named on the site, the app's string is the source — change the app first, the site follows.
- Entities as the neighbours use them: `&mdash;` `&ldquo;` `&rdquo;` `&rsquo;`.

## Patching from a shell
Bash heredocs eat backslashes — patch scripts go through a file written with the Write tool; keep each anchor unique and assert it. Files may be CRLF.
