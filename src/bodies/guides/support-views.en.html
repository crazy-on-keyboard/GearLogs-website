Guide 4.21 · Settings

See when support looked in

See every time GearLogs support opened a read-only view of your workspace: when, as which role, for how long and why.

Before you start

  • Only administrators see the Support views card.
  • A support person never signs in as you. They sign in with their own account, and the view can only read.
  • A view does not need a support request. Support records one of four reasons with every view.
  • Nobody is notified when a view opens. You see it on the card and in System Logs.

  1. Open Settings › Security.

    Open Settings from the side menu, then Security in its list. Support views is the last card on the page.

    1. Settings in the side menu.
    2. Security in the Settings list.
    3. Support views · last 90 days: administrators only.

    Security opens for every member, for their own password and two-factor. Only administrators see this card.

  2. Read the list.

    Each row is one time GearLogs support looked in. The newest is on top.

    1. The title with its (i): the (i) says what support can do, and that every view is listed here and in the log.
    2. The list. With no views in 90 days, it reads No support views in the last 90 days.

    When there are views, the list has four columns. When: the date and minute the view opened. As: the role support saw your workspace as — Administrator, Operator, User or Viewer. Length: how many minutes it lasted. Reason: Support request, Billing check, Incident or Other. A view that is still open reads Live now beside its minutes. A view older than 90 days leaves the list.

  3. Read what a view is.

    The (i) beside the title explains the card in two parts.

    1. The (i) beside Support views · last 90 days.
    2. What this is: every view of the last ninety days, and what each row tells.
    3. How it works: a view is a support operator’s own sign-in, limited to reading as the role shown.

    The view opens in a tab of its own, under a red strip. The strip names your workspace, the role and the time left. Everything support tries to save there is refused, so nothing in your workspace can change. The view ends by itself when its time runs out, or when support ends it. GearLogs sets one length for every view, and it cannot be extended.

  4. Find the line in System Logs.

    The same fact lands in System Logs the moment a view opens.

    1. System Logs in the side menu.
    2. Search Keywords: type read-only view to find the lines.
    3. User and Action Type: pick GearLogs Support and System.

    The line comes from GearLogs Support and carries the SYS tag. While the view is open, it reads read-only view opened as Viewer — support request. When the view ends, the same line gains its length: read-only view as Viewer, 10 min — support request. It is written in your workspace’s language. Administrators, operators and anyone with View everyone’s activity log see it.

Result

You can answer, for the last 90 days, when GearLogs support looked into your workspace, as which role, for how long and why. A view never changed anything in your workspace.

If something is refused

  • The list could not be loaded. The list did not reach you. Open Security again in a moment.
  • No support views in the last 90 days. This is not a fault. Support has not opened a view of your workspace in the last 90 days.
  • Showing the most recent 1,000 entries. Older history is in each person’s or item’s own activity log. System Logs holds the latest 1,000 entries. For an older support line, export Full Activity Log from Data Ops.
