Guide 4.15 · Settings

Turn on two-factor sign-in

Add a six-digit code from your phone to your password, keep a way back in, and require it for the whole workspace.

Before you start

  • Settings › Security opens for every member. Your two-factor is yours alone.
  • You need an authenticator app on your phone. GearLogs names Google Authenticator, Authy and 1Password as examples.
  • GearLogs asks for the code at every sign-in once the workspace requires two-factor. Step 4 turns that on.
  • Requiring it for the whole workspace is for administrators.

  1. Open Settings › Security.

    Open Settings from the side menu, then Security in its list.

    1. Settings in the side menu.
    2. Security in the Settings list.
    3. Your two-factor: your own sign-in.
    4. Workspace two-factor: administrators see this card below it.

    Change password sits above them. Guide 4.9 covers it.

  2. Set up your own two-factor.

    The card tells you where you stand.

    1. Your two-factor and its status: Not set up, Set up — verify to manage or Verified this session.
    2. Set up my two-factor opens the setup window.

    The window Set up your two-factor shows a code to scan with your authenticator app. Or enter this key manually gives the same key as text. Type the 6-digit code the app shows, then press Verify & continue. Ten recovery codes appear next. Each one works once. Copy them with Copy all, keep them somewhere safe, and press I’ve saved them. They are never shown again. Later, Verify my two-factor asks for a code and nothing else.

  3. Keep a way back in.

    Recovery codes let you in when the phone is lost.

    1. The (i) beside Your two-factor.
    2. Its explanation: recovery codes are the way back in, and an administrator can also reset your two-factor.

    On the sign-in code screen, Lost your device? Use a recovery code asks for one of your codes. Press Continue. GearLogs clears the old authenticator and shows a new code to scan straight away, then a fresh set of recovery codes. While the card reads Verified this session, New recovery codes gives you ten new codes, and the old set stops working.

  4. Require two-factor for the whole workspace.

    Workspace two-factor is for administrators.

    1. Workspace two-factor and its state, Off or On.
    2. Turn on stays grey until your own two-factor reads Verified this session. The reason is written under it.

    Turn on asks first: Require two-factor for everyone? Every member is asked to set up two-factor at their next sign-in, and every change then requires the code. Once it is on, the Users screen shows 2FA on or No 2FA beside each member. Reset 2FA clears a locked-out member’s authenticator, and they set up a new one at their next sign-in. It never resets your own or the super administrator’s. Another administrator’s is for a super administrator. Turn off asks first too, and anyone already set up keeps their authenticator.

  5. Know when anything changes.

    Settings › Notifications tells you of every change to your sign-in.

    1. Notifications in the Settings list.
    2. Security, with its two columns: In-app and Email.
    3. Password, two-factor and recovery changes: Always on in both. It cannot be switched off.

    You hear when two-factor is turned on or off, when a recovery code is used, and when an administrator resets your two-factor. When wrong recovery codes are tried on your account, you and your administrators are told. Nothing is locked. A change you did not make means someone else has your account.

Result

With the workspace requirement on, every sign-in asks for the password and the six-digit code, and every change needs it. You keep ten recovery codes for the day the phone is lost, and you hear about every change.

If something is refused

  • That code isn’t right. Try again. The code did not match your authenticator. Type the code the app shows now.
  • Couldn’t start two-step setup. Please try again. The setup window could not start. Close it and try again in a moment.
  • That code isn’t valid or was already used. Each recovery code works once. Try another code from your set. Several wrong codes in a short time tell you and your administrators; nothing is locked.
  • Set up and verify your own two-factor first. Written under a grey Turn on. Set up your own two-factor, or verify it, until the card reads Verified this session.
  • Couldn’t change the setting. Make sure your own two-factor is verified, then try again. The workspace refused the change. Only an administrator verified this session may turn the requirement on or off.
  • Couldn’t generate new recovery codes. Please try again. No new set was made. Your current recovery codes still work.
