Guide 4.8 · Registry

Track each unit by its serial number

Turn on unit tracking for an item, register its units and lots, and hand out, move or repair one unit at a time.

Before you start

  • Turning tracking on, registering units and lots, moving a unit and sending it to repair need the right Create/Edit Items. Administrators and operators have it.
  • Handing a unit out and taking it back need Assign/Return Assets. Administrators, operators and users have it. A sensitive item also needs Assign Sensitive Gear.
  • Writing a unit off needs Write Off / Report Lost Gear.
  • A consumable item cannot be tracked by unit.

  1. Turn on unit tracking for an item.

    Open the item on the Logistics board with Edit Record, then its Registry tab.

    1. The Registry tab of Edit Item.
    2. The line under the title says whether tracking is on. Off means the item uses a simple stock number.
    3. The switch Track individual units asks before it changes anything.

    For an item with stock, turning it on offers two choices. Rebuild stock as … turns today’s stock into units, each with its own UN code. Start with zero units lets you register the real ones. From then on the stock is the number of units in stock, and the manual + and − are off. Once it is on, Manage units in Registry takes you there.

  2. Find the item’s units in the Property Book.

    Open Registry from the side menu. It opens on Property Book: items, then lots, then units.

    1. Property Book in the band.
    2. The item. Its two numbers are its units: total · in stock.
    3. Lots: the lots of that item. All Units shows every unit.
    4. Units: each unit’s code, serial number, status, condition and holder.

    The other views show the same units another way: Ledger puts every unit in one table, then By Holder, Lifecycle and Contracts. The search box above the panes filters units, serials and codes.

  3. Register units.

    The green + on the Units pane opens Register Units for that item. Register above the panes opens it too.

    1. Item and Lot: where the units go. + New lot… creates a lot on the spot.
    2. One, Batch or From file.
    3. Serial number (optional): the maker’s serial. One this item already has is marked Already used for this item.
    4. Register unit adds it. The window stays open for the next one.

    Batch adds up to 500 units at once: Auto codes only, or Stamp a range from a Prefix and a Start no. Either way, every unit gets its own UN code.

  4. Import a list of serial numbers.

    From file registers many real serial numbers at once.

    1. From file.
    2. Paste one serial per line, or a serial and a lot per line.
    3. Choose a file reads a .csv or .txt file instead.
    4. Preview shows how the file was read. Nothing is written yet.

    Then Import adds the rows, up to 2,000 at a time. Duplicates are skipped and reported, and a lot the file names that does not exist yet is created. The report counts what was Added, Skipped and Invalid, row by row.

  5. Group units into lots.

    A lot is a batch made or received together. The green + on the Lots pane opens Add Lot.

    1. Lot number: the supplier’s batch number. GearLogs also gives every lot its own LT code.
    2. Warranty until: the warranty for every unit in the lot.
    3. Expiry: for perishables.
    4. Save creates the lot.

    A lot’s row edits it, attaches it to a contract, or deletes it. A lot that still holds units cannot be deleted. To move a unit into a lot, drag its row onto the lot, or use Move unit.

  6. Act on one unit.

    Each unit’s row carries its own buttons, by what the unit can do now.

    1. Assign hands a unit in stock to a person: pick the person, add a note if you like, then Assign.
    2. Send to repair takes it out of stock until it comes back.
    3. Move unit moves it to another lot, or to another item while it is in stock.
    4. Write off writes it off with a reason: Lost, Stolen, Destroyed or Other.

    An issued unit shows Return instead, and asks first. A unit in repair shows Back from repair. Condition, Warranty and Coverage sit on every active row. A unit marked NEEDS REPAIR asks before it is handed out, and one marked UNSERVICEABLE cannot be. The person gets a receipt to sign on My Gear, and every act is written to the unit’s history.

  7. Send a unit to repair.

    Send to repair asks first, in Send to repair?

    1. The unit, by its code, serial number and item.
    2. Reason for repair (optional): what is wrong.
    3. Send to repair moves it to IN REPAIR.

    The reason is kept in the History line of that repair. When the unit comes back, Back from repair returns it to stock as SERVICEABLE or NEEDS REPAIR, with a note.

Result

Every tracked item counts its stock from its units, and each unit carries its own serial number, lot, holder and history.

If something is refused

  • Already used for this item That serial number is already registered for this item. Register unit stays grey until you change it.
  • Return this item’s current assignments before turning on unit tracking. Someone still holds this item. Take it back first, then turn tracking on.
  • Moving to a different item is only allowed while the unit is in stock — return it first. The unit is out with someone or in repair. It can still change lot; to change item, bring it back to stock first.
  • This item is sensitive — you need the Assign Sensitive Gear permission to hand it out. You pressed Assign on a sensitive item without that right. Ask someone who holds Assign Sensitive Gear.
  • Too many rows — import up to 2,000 at a time. The file has more than 2,000 rows. Split it and import each part.
