Guide 4.19 · Data Ops

Bring your lists in from a spreadsheet

Bring in items, people, sign-in accounts or serial numbers from a .csv file. You see how the file was read before anything is saved.

Before you start

  • Import Center opens only for a super administrator. For everyone else it is greyed out, with a lock.
  • Save the spreadsheet as a .csv file first.
  • Each card has its own Template. Start from it: the first row names the columns in English, the way the importer reads them.
  • Import up to 2,000 items or people at a time.

  1. Open the Import Center.

    Open Data Ops from the side menu, then Import Center in its rail.

    1. Data Ops in the side menu.
    2. Import Center in the Data Ops rail.
    3. The line above the cards: drop each file on the card that matches it.
    4. The four cards: Import Logistics, Import Personnel, Import Users and Import Registry.

    Import Logistics brings in items with their stock. Import Personnel brings in people. Import Users creates sign-in accounts. Import Registry adds serial-numbered units to items that already track units.

  2. Fill the template and drop the file.

    Every card works the same way. Here: Import Logistics.

    1. The card’s name and what it brings in.
    2. Template downloads a sample .csv with the card’s columns.
    3. Drag the file here, or click to choose it.

    The Logistics columns are name, quantity, location, tab_name, group_name, notes and capacity. Only name is required. Quantity and capacity take whole numbers, up to 999,999,999. A tab or group the file names that does not exist yet is created. A people file needs first_name, last_name and primary_dept. A column the importer does not know is left out, and the preview names it.

  3. Check the preview.

    Nothing is saved yet. The preview shows how the file was read.

    1. The first line: nothing is saved until you confirm.
    2. Will add: the new records the file brings.
    3. The rows set aside: one a rule refused, for a quantity over 999,999,999, and one that matches the Hand Truck you already have. Neither is written over anything.
    4. Import saves the file.

    Cancel closes the preview, and nothing is saved. After Import, the clean rows are saved and the rows set aside wait under the cards. A people file is stricter. A row that breaks a person rule — a name, an e-mail address, a phone number, or an ID number or personal number used twice — refuses the whole file before the preview. A window titled Import failed names a row and a field. A row without a first name, last name or primary department is set aside like any other.

  4. Sort out the rows set aside.

    Rows set aside wait under the cards, each with its reason in your language.

    1. Import Center carries a red count while rows are waiting.
    2. The box under the cards. All Clear means nothing is waiting; otherwise the rows are listed here.

    Pick a row to open it. A row a rule refused shows Validation Error: correct its fields, then press Retry Import. A row that matches a record shows Data Conflict, with the existing and incoming values side by side. Overwrite Existing takes the file’s values. Keep Both (Copy) adds the row as a new record. Discard drops it. Discard and Overwrite Existing ask first. Discard All, Overwrite All and Keep Both act on the whole list, and the first two ask first.

Result

Your items, people and accounts are in GearLogs, and every row that was not saved waits under the cards with its reason.

If something is refused

  • Validation: Quantity can go up to 999,999,999. The row’s quantity is larger than GearLogs counts. The row waits under the cards: correct the number, then press Retry Import. Capacity has the same limit and its own sentence.
  • Validation: Quantity must be a whole number. The quantity holds a fraction. Counts are whole numbers only. Correct it in the row and press Retry Import.
  • Duplicate Name An item with that name already exists, or appears earlier in the same file. For people, the same name in the same primary department. Nothing was written over it: choose Overwrite Existing, Keep Both (Copy) or Discard.
  • Import failed A row of a people file broke a person rule, so the whole file was refused and nothing was saved. The line in the window names a row and a field. Correct the file and import it again.
  • Import failed — nothing was saved. Please try again. The file was refused whole when it was being saved. A file of more than 2,000 items or people is one reason: split it and import each part.
